## Relato da atividade

**Aluno**: Ermesson Andrade — [github.com/Erm2k8](https://github.com/Erm2k8)

O aplicativo é o **Diatinf X**, uma réplica simplificada do X construída *mobile first*
com a paleta da identidade visual da DIATINF. O repositório reúne o frontend web em
`/web` e a api restfull em `/api`.

### Componentes e tecnologias

| Camada | Tecnologias |
| --- | --- |
| Frontend (`/web`) | Vite, React, TypeScript, React Router, CSS puro com custom properties e CSS Modules |
| Backend (`/api`) | Node.js, Express, TypeScript, Zod, JSON Web Token, bcryptjs |
| Banco de dados | PostgreSQL (Neon) via Prisma ORM |
| Autenticação | Usuário e senha com JWT, e login pelo OAuth2 do SUAP |
| Publicação | Vercel |

O protótipo de interface e os tokens de design estão documentados em
[docs/design-tokens.md](docs/design-tokens.md), a partir das telas
[mobile](docs/diatinf-x.jpg) e [desktop](docs/diatinf-x-desktop.jpg).
